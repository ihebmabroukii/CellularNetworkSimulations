# CellularNetworkSimulations

This repository contains a series of **educational mobile network labs** designed to simulate mobile network operations, progressing from **2G to 5G**.  

Each lab focuses on a specific aspect of mobile networks, such as:

- 2G/3G: Basic frame construction, SMS transmission, session management, and authentication.  
- 4G/5G: Advanced concepts such as LTE/NR signaling, IP allocation, and network procedures.

---

## 📘 Purpose

The goal of this repository is to provide a **hands-on learning environment** for students and enthusiasts to understand the key principles of mobile networks:

- How mobile devices communicate with the network.  
- How sessions and identities are managed.  
- How authentication and security are implemented.  
- How the evolution from 2G to 5G changes network architecture and protocols.
